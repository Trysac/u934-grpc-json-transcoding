# Stack

## Used

| Tool | Why |
|---|---|
| .NET 10 (LTS) | `net10.0` target. |
| dotnet CLI | Build, restore, test. |
| dotnet format | Consistent code style. |
| .NET Analyzers | Code quality and security rules (warnings as errors). |
| xUnit + FsCheck | Example-based and property-based testing. |
| coverlet | Code coverage gate (80%). |
| NuGet lock files | Reproducible builds. |
| Gitleaks | Secret detection. |
